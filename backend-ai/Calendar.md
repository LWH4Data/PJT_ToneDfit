# 1. 개요
- 프런트엔드의 캘린더에 사용자는 두 가지 정보를 기록한다.
    - 사용자의 일정에 맞게 사용자가 직접 작성한 메모
    - 사용자가 추움, 더움을 텍스트로 기록.
- 캘린더에 기록된 두 가지 텍스트 정보를 하나의 입력으로 API body로 받는다.

# 2. DataFlow
- API를 통해 전달된 텍스트 데이터는 임베딩되어 OpenSearch내의 임베딩과 비교한 뒤 KNN방식으로 중복없이 약 10 개의 아이템을 API로 반환한다.
    - 반환 형식과 임베딩 모델은 현재 디렉터리의 image_search에 사용되는 clip 모델을 그대로 사용하고, API의 json 형식 또한 동일한 형식을 사용한다.
